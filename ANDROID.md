# Android (APK/AAB) build — AI Super App

**Status: prepared, NOT built.** Phase 11 was produced in an environment with no Android SDK, no Gradle
distribution, no npm registry access and no signing key, so **no APK/AAB exists** and the native Play Billing
plugin (`mobile/android-plugin/PlayBillingPlugin.java`) has **never been compiled or run on a device**.

## Architecture
Next.js server app (API routes, Prisma, NextAuth, server-side AI keys) cannot be bundled into an APK.
The Capacitor Android app is a native shell whose WebView loads your deployed **HTTPS** site (`server.url`).
No secret ships in the APK. Web updates need no new APK.

## Requirements (what was missing here)
- Node >= 20.19 with npm registry access (`npm install`)
- JDK 21, Android Studio (or command-line tools) with an Android SDK platform matching Capacitor's `compileSdk`
  and build-tools; `ANDROID_HOME` set; Gradle (the wrapper is generated by `cap add android`)
- A deployed HTTPS URL for the web app (`CAP_SERVER_URL`), with a production DB, `AUTH_SECRET`, `NEXTAUTH_URL`
- A release keystore (`*.jks`) — keep it OUT of the repo — or Play App Signing
- Google Play Console app + subscription products `ai_super_app_pro_monthly|yearly`, `ai_super_app_premium_monthly|yearly`
  and a service account for server-side verification (`GOOGLE_PLAY_*` env vars, server only)

## Steps
```bash
npm install
export CAP_SERVER_URL=https://your-app.example.com     # must be https
export CAP_APP_ID=com.yourcompany.aisuperapp            # = GOOGLE_PLAY_PACKAGE_NAME on the server
npx cap add android
npm run android:prepare      # installs billing plugin, Billing dependency, hardens the manifest
npx capacitor-assets generate --android   # uses resources/icon.png + splash*.png
npx cap sync android
cd android && ./gradlew bundleRelease     # AAB for Play  (or assembleRelease for an APK)
```
Sign with your keystore (Gradle `signingConfigs` via a git-ignored `keystore.properties`, or Play App Signing).
Verify versions: Capacitor 7 / Play Billing 7.1.1 / target SDK were chosen from knowledge that may be out of date —
check Google Play's current target-API and Billing-Library requirements before release.
